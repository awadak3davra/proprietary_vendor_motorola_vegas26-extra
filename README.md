# vegas26 vendor delta for the AOSP 17 device tree

Proprietary files for the moto g power - 2026 (`vegas26`) that the AOSP 17 tree
([aosp_device_motorola_vegas26](https://github.com/awadak3davra/aosp_device_motorola_vegas26)) needs on top of
jimmielin's public vendor tree
[android_vendor_motorola_mt6835-common-vegas26](https://github.com/jimmielin/android_vendor_motorola_mt6835-common-vegas26)
at `28e63bc935d10f7709e64f92bf66dfe4d195ea0a`. The device-specific vendor tree
([android_vendor_motorola_vegas26](https://github.com/jimmielin/android_vendor_motorola_vegas26) at
`38dedabfb7f991c1d2b4e98323fa1be8fd9c1158`) is used unchanged.

All files come from the stock Motorola firmware for vegas26 (vendor `W1WEOS36.48-22-3-3-4-3`) through the
device tree's `extract-files.py`. They are Motorola and MediaTek property and are not covered by an open source
license. Nothing device-unique (nvram, nvdata, persist, calibration, keys, identifiers) is included.

## Contents (overlaid onto `vendor/motorola/mt6835-common-vegas26`)

| Path | Why |
|---|---|
| `Android.bp`, `mt6835-common-vendor.mk` | Regenerated by `setup-makefiles.py` for the A17 `proprietary-files.txt` |
| `proprietary/system_ext/priv-app/LPPeService/LPPeService.apk` | Added to the A17 list (stock) |
| `proprietary/vendor/lib64/libpowerhalwrap_vendor.so`, `vendor.mediatek.hardware.mtkpower_applist-V1-ndk.so` | Added to the A17 list (stock) |
| `proprietary/vendor/lib64/libformatter-v33.so`, `mt6835/libmnl-v33.so` | Stock `libformatter.so` and `libmnl.so` renamed (`FIX_SONAME`), as the A17 list requires (Android 17 has its own `libformatter`) |
| `proprietary/vendor/lib64/libcodec2_mtk_vdec.so`, `libcodec2_mtk_venc.so`, `vendor/bin/mnld` | Stock, `NEEDED` entries pointed at the renamed libraries above |
| `proprietary/system_ext/priv-app/ImsService/ImsService.apk`, `MtkGbaService/MtkGbaService.apk` | Stock, patched with the device tree's `patches/ImsService` and `patches/GbaService` (Android 17 API changes) |
| `aosp-compat/` | Output of the device repo's `scripts/gen-compat.py`: two AOSP VNDK libraries renamed for the stock blobs, and the stock `libprotobuf-cpp-lite-3.9.1.so` |

`removed-files.txt` lists files of the jimmielin tree that the A17 lists no longer reference (VT service, older
MediaTek HIDL libraries): they stay on disk but are not built. `files.sha256` has checksums of every file here.

## Use

The device repo's `scripts/apply.sh` takes this repository as its second argument and copies it over
`vendor/motorola/mt6835-common-vegas26`. Do not put this repository inside the AOSP tree itself: its
`Android.bp` would clash with the vendor tree's.

Alternative without any downloaded blobs: extract everything from your own stock dump with
`device/motorola/vegas26/extract-files.py` (see the device repo README).
